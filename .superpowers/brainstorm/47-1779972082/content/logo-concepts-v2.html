课记 — 重新设计

让 logo 和「课记」真正产生关联。也更新了 Tally 方案作为对比。

方案 A：课记 — 抽象图形

每个设计都从「课」和「记」两个字的含义出发

课记

A1 — 书页 + 对勾

打开的书本 = 课程教学，对勾 = 记录完成/已结账。名字和图形直接呼应。

课记

A2 — 铅笔 + 记录线

黄色铅笔 = 教学书写，蓝色横线 = 记账记录。直译「上课→记下来」。

课记

A3 — 「记」字笔画抽象

「记」字拆成几何线条：言字旁 = 三条横线，己 = 一笔回环。深蓝底 + 金色收笔。

方案 B：Tally — 抽象图形

Tally

B1 — 正字计数

|||| 四竖 = 课程计数，/ 斜线 = 结算。名字和图形天然一体。

Tally

B2 — T + 计数条

品牌首字母 T 搭配递减横线，代表账单逐笔清掉。蓝色底，干净现代。
